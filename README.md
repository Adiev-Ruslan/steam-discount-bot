# Steam Discount Bot

Telegram-бот для отслеживания скидок на игры в Steam.

## Возможности

- Получение информации об игре по App ID
- Просмотр текущей цены
- Просмотр размера скидки

## Технологии

- Python
- aiogram
- aiohttp
- Steam API

## Запуск

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```
